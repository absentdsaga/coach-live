# Coach Live

1st place, Healthcare track, eMerge AI Hackathon (Miami, Oct 17 2026). Built by Dioni Vasquez, Max Goldstein and Emily Mensching.

A live AI coach for cancer health-coaching calls: it scores every coach line as it is spoken, flags safety lines the moment they happen, and swings a desk gauge between good and bad.

**Try it:** https://coach-live-dioni.zocomputer.io
